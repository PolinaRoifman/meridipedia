# Меридипедия

Откройте папку в VS Code и запустите `index.html`:
- расширение **Live Server** → правый клик по index.html → Open with Live Server, или
- просто откройте index.html в браузере (двойной клик).

Файлы: index.html (страницы и карта), style.css, app.js (переключение страниц, график, анкета, форма), img/ (карты рельефа, климата, растительности).
